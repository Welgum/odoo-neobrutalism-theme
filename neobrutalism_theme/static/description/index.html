Installation

  1. Place neobrutalism_theme on your server's existing add-ons path and restart Odoo.
  2. As an administrator, activate developer mode and update the Apps list.
  3. Remove the default Apps filter, search for Neo Brutal, and install.
  4. Reload Odoo. Select a shared accent in Settings, or use the top-bar moon to try night mode.

Compatibility

  • Tested on Odoo 19 Community, self-hosted.
  • Depends on standard web and base_setup only.
  • No npm, pip, external fonts, CDNs or activation service.
  • Not installable on Odoo Online.
  • Odoo.sh source deployment is possible; Enterprise-specific screens and Odoo.sh deployment have not been verified.

Before you install

This is a backend theme. Public websites, portals, POS, login pages, emails and PDF reports are outside its scope. Discuss, Calendar, CRM, Project and standard graph/pivot views are checked on Odoo 19 Community. Specialized editors, Studio, spreadsheets, custom charts and third-party themes have not been individually verified. Check your installed apps in a staging database first.

The module adds no telemetry or external requests. Shared colors stay in your database and personal preferences stay in your browser. If browser storage is blocked, personal changes last for the current page.

To remove the theme for yourself, disable it in Appearance. To remove it for everyone, uninstall the module in Apps and reload Odoo. The theme does not own business records.
