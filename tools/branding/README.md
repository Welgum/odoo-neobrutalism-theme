# RivetFox marketplace identity

The fox artwork is the header mark from https://rivetfox.pro/, retrieved on 2026-09-22 and reused for the publisher’s own theme artwork at their request. The SVG geometry and orange/cream colors are preserved; its ink is fixed to the site’s `#252520` for predictable rendering. The lowercase wordmark and orange period follow the site.

`space-grotesk-latin.woff2` is the same Space Grotesk Latin variable font served by that site. Its SIL Open Font License is retained in `OFL-Space-Grotesk.txt`; source: https://github.com/google/fonts/tree/main/ofl/spacegrotesk.

These files are local, reproducible inputs to the promotional renderers only. They are not loaded by Odoo or embedded as executable content in marketplace HTML. Rendered GIFs/PNGs carry the publisher mark; the app icons remain theme-specific. Keep this directory identical in both theme repositories.
